    When the cinematic starts, I get an unhandled exception error.

      Some programs remain running constantly in the background of the Windows desktop (AltaVista's free internet service's ad banner, for example). When Diablo II Expansion tries to run full-screen, these programs can create conlicts, causing an Unhandled Exception error. Before running Diablo II Expansion, close all applications running in the background.


    To close programs running in the background:

      Press the <Ctrl>, <Alt>, and <Delete> keys simultaneously. This brings up the Windows Task Manager. End Task on all programs other than Explorer and Systray.
      Note: These programs will restart when you reboot your computer. This is not a permanent change.


    To modify your startup files:
    • Press the Start Button and select "Run." Type in "msconfig" and press Enter.
    • Select the Startup tab.
    • Uncheck each box and press OK.
    • When the "System Settings Change" window appears, press OK to restart your computer.
      Note: To start these programs again, you will need to run "msconfig" again, re-check each box, and reboot your computer.
