    Gameplay Is Slow or Choppy:

    If your game seems to speed up after periodically slowing or pausing completely, you should try the following steps.

    Close all TSRs running on your system:

    Closing Non-Essential Programs in Windows 95/98

    1. Press the <Ctrl>, <Alt>, and <Delete> keys simultaneously. This brings up the Windows Task Manager.
    2. Select each program (other than Explorer and Systray) and click on the "End Task" button.
      Note: These programs will restart when you reboot your computer.
    Closing Non-Essential Programs in Windows NT/2000:
    1. Press the <Ctrl>, <Alt>, and <Delete> keys simultaneously to bring up a security screen.
    2. Press the Task Manager button to view a window listing each active program.
    3. Select each program and click "End Task." Repear steps 1 and 2 to bring up the list again. Repeat until all programs have been closed.
      Note: If your system locks up or reboots, you will need to contact your computer's manufacturer to find out how to close these programs safely. If your system does lock up, turn the power off, wait 10 seconds, and then turn the power back on.

    ***Neither Explorer or Systray will show as active tasks. This list will only show running applications that have open (Visible) windows. Any programs running from the system tray, including services like virus scanners or network tools, will be listed in the process list. Closing virus scanners will always improve your performance considerably, but remember to restart them once you've finished playing!

    Check the network card and its drivers.

    Check the website of your network card's manufacturer and confirm that you are using the most recent drivers for your network card. Also, be sure that your network card is firmly seated in the slot. Loose cards can cause communication problems, resulting in a loss of data that causes pausing and choppiness.

    Set the computer's role to Network Server:

    1. Right-click on My Computer.
    2. Select Properties.
    3. Click on the Performance tab.
    4. Click on the File System button.
    5. Set the typical role of this computer to Network Server.
    6. Click OK and reboot your system.

    If you are currently running in 3D mode, switch to 2D mode.

    1. Click on Start>Programs>Diablo II Expansion>Video Test. Run the Video Test and select the 2D video option.

    Run Defrag and Scandisk on your hard drive.

    If you have been having any Windows or hard drive problems, you should run Scandisk and Defrag on your hard drive. It's a good practice to run Scandisk and Defrag regularly to keep your system at peak performance.

    To run Scandisk:

    • Click on Start>Programs>Accessories>System Tools.
    • Click on the Scandisk icon.
    • Click Standard for a quick scan or Thorough for a more detailed (but slower) scan.
    • Make sure that "Automatically Fix Errors" is checked.
    • Select the hard drive you want to scan and click Start.

    To run Defrag:

    • Click on Start>Programs>Accessories>System Tools.
    • Click on the Defrag icon.
    • Select the hard drive you want to defragment.
    • Click OK to start the scan.

    If you have lots of hard drive space, set your Virtual Memory settings high (making sure that the Min and Max settings have the same value).

    • We recommend that you have at least 350 megabytes of hard drive space available.
    • Make sure you have run Defrag & Scandisk before you change your Virtual Memory settings.

      Windows 95/98

      1. Right-click on "My Computer" and select "Properties" to bring up the "System Properties" screen.
      2. Left-click on the "Performance" tab.
      3. Left-click on the Virtual Memory button.
      4. Check the box labeled "Let me specify my own Virtual Memory settings."
      5. Put a check in the "Let me specify my own Virtual Memory settings" area.
      6. Set the minimum and maximum amounts to twice the amount of RAM you have in your computer.
        For example:
        • 32-128 MB RAM: Min 300, Max 300.
        • 192 MB RAM: Min 384, Max 384.
        • 256 MB RAM: Min 512, Max 512.
      7. Left-click on "Set" to apply the changes.
      8. Reboot your computer.

      Windows 2000:

      1. Right-click on "My Computer" and select "Properties" to bring up the "System Properties" screen.
      2. Left-click on the "Advanced" tab.
      3. Left-click on the "Performance Options" tab.
      4. Left-click on the "Change..." button to bring up the "Virtual Memory" screen.
      5. Set the minimum and maximum amounts to twice the amount of RAM you have in your computer.
        For example:
        • 32-128 MB RAM: Min 300, Max 300.
        • 192 MB RAM: Min 384, Max 384.
        • 256 MB RAM: Min 512, Max 512.
      6. Left-click on "Set" to apply the changes.
      7. Reboot your computer.

      Windows NT

      1. Right-click on "My Computer" and select "Properties" to bring up the ""System Properties"" screen.
      2. Left-click on the "Performance Options" tab.
      3. Left-click on the "Change..." button to bring up the "Virtual Memory" screen.
      4. Set the minimum and maximum amounts to twice the amount of RAM you have in your computer.
        For example:
        • 32-128 MB RAM: Min 300, Max 300.
        • 192 MB RAM: Min 384, Max 384.
        • 256 MB RAM: Min 512, Max 512.
      5. Left-click on "Set" to apply the changes.
      6. Reboot your computer.

      If you are currently running in full screen mode, run the game in windowed mode.

      1. Right-click on the Start Button.
      2. Click on Programs>Diablo II Expansion.
      3. Right-click on the Diablo II Expansion shortcut and select properties.
      4. In the Target Field, add a " -w" after the quotes (i.e., "C:\Program Files\Diablo II Expansion\Diablo II Expansion.exe" -w ).
      5. Click OK.

      Be sure that you are running the latest version of your Motherboard Bios.

      If you are experiencing low frame-rates and sluggish gameplay in Diablo II Expansion, make sure that you are running the latest version of your Motherboard Bios Software. Often this comes on a floppy diskette along with the motherboard itself, but it should also be available on the manufacturer's website.

      Check if you have a VIA motherboard.

      VIA Motherboard Users should download the "4-in-1" driver update, which automatically detects and updates IRQ, AGP, IDE, and INF settings. This fix should correct sluggish gameplay on high end systems and prevent lockups on VIA motherboards.

      Copy game files to the hard drive.

      If you continue to experience sluggish gameplay and choppiness, you can copy the D2CHAR.MPQ and D2MUSIC.MPQ files from the Diablo II Expansion Play Disk into the Diablo II Expansion directory on your hard drive. This should help reduce CD-access and read times.
