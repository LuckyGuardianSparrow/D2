    Most video and sound problems can be solved by the following steps:
    • Contact your computer manufacturer or video and sound card manufacturer (if purchased seperately) to find out what version of DirectX their latest drivers support.
    • Download and install the version of Direct X they recommend.
    • Run the video test program and use the default setting.
    • If problems persist, run the video test program and set the video mode to Direct Draw.

    Steps to run the Video Test program to select the video mode:

    • Click on the Start Button
    • Select Programs
    • Select Diablo II: Lord of Destruction
    • Click on Video Test

    Video Modes supported by Diablo II Expansion:

      Diablo II Expansion supports Glide™ and Direct 3D™ compatible video cards with at least 8 MB of video RAM.
      Direct 3D™ requires 64 MB of system RAM.
      Diablo II: Lord of Destructions's resolution defaults to 640 x 480, and the Battle.net chat interface is set at 800x600.

    Skipping Sound:

    • Click Start, Settings, Control Panel, then double-click on Multimedia.
    • Make sure your sound card is set to be the "Preferred Device."
    • Make sure "Use only preferred devices" is checked.

    Sounds do not match the character animations in the choose a class menu:

    • Click Start, Settings, Control Panel, then double-click on Multimedia.
    • Make sure "Use only preferred devices" is checked.
    • Adding more RAM may also fix this problem.
